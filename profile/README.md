## What CSI CSiBridge Is

CSI CSiBridge is a bridge workspace for alignments, spans, and decks rather than a building grid. CSI CSiBridge lane loading places lanes and vehicles on that same superstructure model for moving-load checks. The bridge layout keeps abutments, bents, and spans visible before the submittal set is prepared.

Bridge groups open CSI CSiBridge when the structure is a deck on an alignment, not a stack of building stories. CSI CSiBridge keeps layout, deck, and lanes together ahead of the review.
